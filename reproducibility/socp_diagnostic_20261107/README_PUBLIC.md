# Saved SOCP representation diagnostic

This is a separate single saved 37-point subproblem, not an end-to-end search
experiment. The supplied LP models, saved solutions, result tables and
`reproduce.py` document the representation diagnostic reported with the revision.
Implied coordinate bounds yielded a solution for this subproblem; the online
comparisons were not rerun with those bounds.

Original solver `.log` files are retained locally and omitted from this public
copy because they contain license-identifying metadata. `SHA256.csv` is the
original full-bundle inventory and therefore also lists these omitted files.
`PUBLIC_SOURCE_MANIFEST.json` in the sibling revision directory identifies the
exact original bytes of the public files. A Gurobi installation and license are
needed to run the diagnostic solver script. It is not called by saved-result
reproduction. No solver was launched during publication of this material.
